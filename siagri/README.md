# Skills do Siagri

Cada pasta contém uma skill para uma tarefa específica. Mantenha campos e procedimentos compartilhados em referências comuns apenas quando forem necessários a mais de uma skill.

| Skill | Uso |
|---|---|
| [auditoria-campos-rtm-siagri](auditoria-campos-rtm-siagri/SKILL.md) | Auditar campos de notas em relatórios RTM e distinguir consulta, metadados, coluna visível e valor efetivo. |

Ideias para futuras skills, conforme a necessidade e após validação em dados reais: importação de notas, conciliação fiscal e diagnóstico de erros do ReportBuilder.

A primeira skill inclui um [catálogo de tabelas e campos em TSV](auditoria-campos-rtm-siagri/referencias/catalogo-campos-siagri.tsv), convertido da planilha fornecida para facilitar busca por nome de tabela ou campo. O arquivo contém definições de estrutura, sem registros de notas.
